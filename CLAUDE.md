# AWS SAA-C03 notes

An Obsidian vault of study notes for the AWS Certified Solutions Architect – Associate (SAA-C03) exam. Each root-level `.md` file is one note, and its filename is the topic. Images live in `_assets/`. Obsidian Git auto-commits vault backups.

- **Notes are the user's own. Don't edit them unless asked.**
- **Quizzes**: `QUIZ.md` is the spec and `/quiz` (`.claude/skills/quiz/SKILL.md`) is the procedure. Quiz runs live in `Quizzes/` and are committed straight to `main`.
