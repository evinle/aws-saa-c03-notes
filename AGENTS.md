# Agent guide

An Obsidian vault of AWS SAA-C03 study notes. Each root-level `.md` file is one note, and its filename is the topic. Don't edit notes unless asked.

To create, run or grade a practice quiz, follow `QUIZ.md` (spec) and `.claude/skills/quiz/SKILL.md` (step-by-step procedure). Quiz runs live in `Quizzes/` and are committed straight to `main`.
