# Vertical 
- More CPU and memory
- Resizing an EC2 instance
	- Restart - downtime
	- Scale during outage windows
	- Larger instances often carry a $ premium
	- Always an upper cap - instance size

# Horizontal 
- More instances
- Needs Load Balancer
- Need to keep sessions in mind
- Requires app consideration or off-host sessions
- No disruption while scaling
- No scaling limit
- Often less expensive
- More granular
