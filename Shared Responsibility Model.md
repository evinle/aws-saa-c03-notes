## Security Perspective
- AWS is responsible for the security 'of' the cloud
- You're responsible for the security 'on' the cloud
![[Pasted image 20260425190400.png]]
- EC2, AWS manages
	- Region, AZ 
	- Compute 
	- Storage, DB, Networking
	- Software to manage, web console, cloud share
	You manage
	- Client data
	- Encryption
	- Networking traffic protection
	- OS, Network, Firewall
	- Application, IAM
	- Customer Data
