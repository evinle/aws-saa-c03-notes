- Raw CPU, mem, storage & storage type
- Resource ratios
	- Compute = more CPU, less memory
	- Caching = more memory, less CPU
- Storage + data network bandwidth
- System architecture (ARM/x86) / vendor (Intel/AMD)
- Additional features & capabilities
	- GPU
	- FPGA (special CPU)

# Categories
- General Purpose - default - balanced, for "diverse" workloads
- Compute Optimized - media, hpc, scientific, gaming, ML
- Memory Optimized - large in memory sets, dbs
- Accelerated Computing - GPU, FPGA
- Storage Optimized - Sequential and random IO , data warehousing, elastisearch, analytics

# Instance Type
- Eg. R5dn.8xlarge
- R - family 
- 5 - generation
- dn (can vary) - additional capability
	- a - amd
	- d - nvme
	- n - network optimised
	- e - extra capacity (ram/storage)
- 8xlarge - size
